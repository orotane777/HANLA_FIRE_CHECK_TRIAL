# Fire extinguisher photo trial

Public mobile camera and QR reading trial. This repository contains built static files only.

Open the site on a phone over HTTPS and allow camera access. Use the QR labels page to print FIRECHECK-TEST-001. Captured photos are processed in the browser and are not uploaded or saved.

This is a trial; it does not certify extinguisher condition or completion of a fire safety inspection.

The QR decoder license is included in zxing-wasm-LICENSE.txt.
