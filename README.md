# Fire extinguisher photo trial

Public mobile QR camera trial with private, signed-in photo storage. sticker-test.html offers a local-only 20-second sticker placement reading trial. This repository contains built static files only.

Use FIRECHECK-TEST-001 from labels.html. Sign in with the prepared trial account to save a photo. Reopen #records with the same account to see the latest saved photo and server registration time. Public signup is disabled.

Photos are stored in a private Supabase bucket and are not committed to this repository. Synthetic sample mode does not save records. This trial does not certify extinguisher condition or completion of an inspection.

The QR decoder license is included in zxing-wasm-LICENSE.txt.
